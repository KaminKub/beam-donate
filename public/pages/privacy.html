0. ผู้ควบคุมข้อมูลส่วนบุคคล (Data Controller)

TipKub ดำเนินการโดย นามแฝง "Kaminkub" (ผู้ดำเนินการ / Sole Operator) — บุคคลธรรมดาในฐานะผู้ควบคุมข้อมูลส่วนบุคคลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) หากมีข้อสงสัยหรือต้องการใช้สิทธิ์ใดๆ ติดต่อได้ที่:

  • ช่องทางติดต่อ: contact@tipkub.me
  • เว็บไซต์: tipkub.me

สำหรับข้อมูลโดเนท (ชื่อผู้บริจาค ข้อความ และรายการบริจาค) สตรีมเมอร์เป็นผู้ควบคุมข้อมูลส่วนบุคคล (Controller) และ TipKub เป็นผู้ประมวลผลข้อมูลส่วนบุคคล (Processor) ซึ่งประมวลผลข้อมูลดังกล่าวตามคำสั่งและการตั้งค่าของสตรีมเมอร์

1. ข้อมูลที่เราเก็บรวบรวม

เพื่อการใช้งานแพลตฟอร์ม TipKub เรามีการเก็บรวบรวมข้อมูลที่จำเป็นดังนี้:

  • ข้อมูลจาก Twitch: เราใช้ระบบ OAuth ของ Twitch เพื่อยืนยันตัวตน โดยเก็บข้อมูลพื้นฐาน เช่น Twitch ID, ชื่อผู้ใช้งาน (Username) และรูปโปรไฟล์ เพื่อใช้ในการสร้างและจัดการหน้าโดเนทของคุณ
  • ข้อมูลที่ไม่มีการจัดเก็บ: เพื่อความเป็นส่วนตัวสูงสุด ระบบของเราไม่มีการเก็บข้อมูลอีเมล (Email) หรือรหัสผ่าน (Password) ของผู้ใช้งานในฐานข้อมูลโดยเด็ดขาด
  • ข้อมูลการตั้งค่า: ข้อมูลการปรับแต่งหน้าโดเนทที่คุณกำหนดเองใน Dashboard จะถูกบันทึกไว้ในฐานข้อมูลของเรา
  • ข้อมูลการรับเงิน: ข้อมูลที่จำเป็นสำหรับการรับเงิน เช่น เบอร์โทรศัพท์, หมายเลขบัตรประจำตัวประชาชน, รหัสรับเงินพร้อมเพย์, เลขบัญชีธนาคาร และชื่อเจ้าของบัญชีธนาคาร (ชื่อ-นามสกุลจริง) จะถูกเก็บไว้ในฐานข้อมูล โดยจะถูกเข้ารหัสด้วย AES-256-GCM ก่อนจัดเก็บเสมอ (ยกเว้นชื่อธนาคาร ซึ่งเป็นข้อมูลทั่วไปที่ไม่ระบุตัวบุคคล)
  • ข้อมูล API ของบุคคลที่สาม: ข้อมูล API ของ SlipOK ที่ผู้ใช้งานกรอกเองจะถูกเข้ารหัสก่อนจัดเก็บเช่นกัน (TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการของ SlipOK)
  • ข้อมูล API ของผู้ให้บริการ TTS: ข้อมูล API ของผู้ให้บริการ Text-to-Speech (Google Cloud / Gemini) ที่สตรีมเมอร์กรอกเอง จะถูกเข้ารหัสด้วย AES-256-GCM ก่อนจัดเก็บ และไม่มีการส่งกลับไปแสดงผลฝั่งผู้ใช้งาน (TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการของผู้ให้บริการดังกล่าว)
  • ข้อมูลจาก TrueMoney Webhook (เฉพาะเมื่อเปิดใช้งาน): เมื่อสตรีมเมอร์เปิดใช้งานระบบ Webhook ของ TrueMoney TipKub จะได้รับการแจ้งเตือน (JWT Notification) จาก TrueMoney เมื่อมีการโอนเงินเข้า Wallet สิ่งที่ TipKub บันทึก ได้แก่ ยอดเงิน เลขอ้างอิงธุรกรรม และเบอร์โทรศัพท์ผู้โอนในรูปแบบ mask (เช่น 0812345678 → 08xxxx5678) — ไม่เก็บเบอร์เต็ม TipKub ไม่แตะเงิน ไม่รับ ไม่โอน ไม่ถือ float — เงินโอนตรงจาก donor ไปยัง TrueMoney Wallet ของสตรีมเมอร์ผ่าน TrueMoney โดยตรง TrueMoney (Ascend Money) เป็น Controller ของข้อมูลผู้ส่งฝั่งต้นทาง

ชื่อ Cookie วัตถุประสงค์ อายุ Attributes
tipkub.sid รักษา session การล็อกอินของ streamer เพื่อจัดการ Dashboard โดยไม่ต้อง login ซ้ำ 7 วัน (หรือจนกว่าจะ logout) httpOnly, Secure, SameSite=Lax

3. การรักษาความปลอดภัยและการแบ่งปันข้อมูล

เราให้ความสำคัญกับความเป็นส่วนตัวของคุณอย่างสูงสุด:

  • เราไม่มีการขายข้อมูลส่วนบุคคลของคุณให้กับบุคคลที่สาม
  • ข้อมูลการเชื่อมต่อ API ของบริการชำระเงิน (SlipOK ซึ่ง TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการ) รวมถึงเบอร์โทรศัพท์และรหัสรับเงินพร้อมเพย์จะถูกเข้ารหัสด้วย AES-256-GCM และเก็บรักษาเป็นความลับ ใช้เพื่อการประมวลผลยอดบริจาคเท่านั้น
  • กุญแจถอดรหัส (Encryption Key) จะถูกเก็บรักษาโดยผู้ให้บริการเท่านั้น ไม่มีการเปิดเผยต่อบุคคลที่สาม

ผู้ให้บริการ ข้อมูลที่ส่ง วัตถุประสงค์
Twitch Twitch ID, ชื่อผู้ใช้, URL รูปโปรไฟล์ ยืนยันตัวตน (OAuth)
Streamlabs Streamlabs ID, ชื่อผู้ใช้, URL รูปโปรไฟล์, access token ยืนยันตัวตน (OAuth)
SlipOK ภาพสลิปโอนเงิน (ชั่วคราว ไม่จัดเก็บ), API key ของ streamer ตรวจสอบสลิปโอนเงิน
Cloudflare R2 รูปโปรไฟล์, รูป header, รูปพื้นหลัง Dashboard จัดเก็บและส่งมอบรูปภาพ (CDN)

Google Translate (TTS) (เสียงระดับฟรี) ข้อความของผู้บริจาค (donor message) ที่เปิด Text-to-Speech แปลงข้อความเป็นเสียงสำหรับ Alert Overlay
Microsoft (ผ่าน Edge TTS แบบไม่เป็นทางการ) ข้อความของผู้บริจาค (donor message) ที่เปิด Text-to-Speech และเลือกเสียงเปรมวดี/นิวัฒน์ แปลงข้อความเป็นเสียงสำหรับ Alert Overlay — หมายเหตุ: ไม่ใช่บริการทางการของ Microsoft ปัจจุบัน endpoint ปฏิเสธการเชื่อมต่อ (ใช้งานไม่ได้จริง) TipKub ไม่รับรองความพร้อมใช้งาน
Google Cloud TTS ข้อความโดเนท (ชื่อผู้บริจาค + ข้อความ) สังเคราะห์เสียง TTS (เฉพาะเมื่อสตรีมเมอร์เปิดใช้)
Vertex AI (Gemini) ข้อความโดเนท (ชื่อผู้บริจาค + ข้อความ) สังเคราะห์เสียง TTS ผ่านผลิตภัณฑ์ Google Cloud คนละตัวกับ Google Cloud TTS ด้านบน (เฉพาะเมื่อสตรีมเมอร์เปิดใช้)
TrueMoney (Ascend Money) เบอร์โทรศัพท์ผู้โอน (mask แล้ว), ยอดเงิน, เลขอ้างอิงธุรกรรม — ส่งมาจาก TrueMoney ผ่าน Webhook JWT (TipKub รับแจ้งเตือน ไม่ได้ส่งข้อมูลออกไป) ยืนยันการโอนเงินเข้า TrueMoney Wallet ของสตรีมเมอร์ (เฉพาะเมื่อเปิดใช้งาน Webhook)

⚠️ หมายเหตุผู้ให้บริการ TTS: ข้อความ donor message ทุกชิ้นที่เปิดฟีเจอร์ TTS จะถูกส่งไปยังผู้ให้บริการสังเคราะห์เสียงที่สตรีมเมอร์เลือกใช้ (Google Translate, Google Cloud TTS, Vertex AI (Gemini) หรือ Microsoft ผ่าน Edge TTS แบบไม่เป็นทางการ) เพื่อแปลงเป็นเสียง ซึ่งอาจรวมถึงชื่อผู้บริจาค กรุณาระมัดระวังข้อมูลส่วนบุคคลในข้อความ Edge TTS ไม่ใช่บริการทางการของ Microsoft และปัจจุบัน endpoint ใช้งานไม่ได้จริง (TipKub ไม่รับรองหรือรับประกันความพร้อมใช้งาน)

3.2 การจัดเก็บรูปภาพใน Cloudflare R2

  • รูปโปรไฟล์, header background และ page background ที่ streamer ตั้งค่าไว้จะถูกจัดเก็บใน Cloudflare R2 (Object Storage) ซึ่งตั้งอยู่ใน Region Asia Pacific

4. นโยบายเกี่ยวกับข้อมูลสลิปโอนเงิน

เกี่ยวกับการตรวจสอบสลิปโอนเงินผ่านระบบของ TipKub:

  • ไม่มีการจัดเก็บไฟล์สลิป: รูปภาพสลิปที่ผู้โดเนทอัพโหลดจะถูกส่งไปยัง SlipOK API เพื่อตรวจสอบเท่านั้น ไม่มีการจัดเก็บไฟล์สลิปไว้ที่ Server ของ TipKub เด็ดขาด เมื่อการตรวจสอบเสร็จสิ้น ไฟล์สลิปจะถูกลบออกจากหน่วยความจำของเซิร์ฟเวอร์ทันที
  • ข้อมูลที่บันทึก: ระบบจะบันทึกเฉพาะข้อมูลผลลัพธ์จากการตรวจสอบ เช่น ยอดเงินโอน, เลขอ้างอิงธุรกรรม, และชื่อผู้โอน ลงในฐานข้อมูล เพื่อใช้ในการยืนยันการชำระเงินและแสดงใน Dashboard
  • SlipOK เป็นบุคคลที่สาม: การตรวจสอบสลิปดำเนินการโดย SlipOK ซึ่งเป็นบริการบุคคลที่สาม ผู้ใช้งานต้องสมัครบัญชีกับ SlipOK โดยตรง และยอมรับนโยบายความเป็นส่วนตัวของ SlipOK แยกต่างหาก

TTS API Key (Google Cloud / Gemini) เก็บจนกว่าสตรีมเมอร์ลบ key หรือปิดบัญชี เข้ารหัส AES-256-GCM ก่อนจัดเก็บ
รูปภาพ (Cloudflare R2) จนกว่าจะลบบัญชีหรือเปลี่ยนรูป ลบออก R2 ภายใน 30 วันหลังเปลี่ยน
รายการโดเนท (Pending) 30 นาที หมดเวลาอัตโนมัติ
รายการโดเนท (Expired) 7 วัน ลบอัตโนมัติ
รายการโดเนท (Completed) 180 วัน ล้างอัตโนมัติทุก 6 เดือน
Session data 7 วันหรือจนกว่าจะ logout Cookie httpOnly, Secure, SameSite=Lax
ภาพสลิปโอนเงิน ไม่เก็บ ส่ง SlipOK แล้วลบจากหน่วยความจำทันที
IP Address + เหตุการณ์ (ip_events) 90 วัน เก็บตาม พ.ร.บ.คอมพิวเตอร์ ม.26 — ลบอัตโนมัติทุกไตรมาส
บันทึก TrueMoney Webhook (webhook log) 90 วัน เก็บ event_id + เบอร์ผู้โอน (mask) + ยอดเงิน เพื่อป้องกัน duplicate — ลบอัตโนมัติ

6. ฐานทางกฎหมายในการประมวลผลข้อมูล (Lawful Basis)

ข้อมูล ฐานทางกฎหมาย
Twitch/Streamlabs ID, ชื่อผู้ใช้ การปฏิบัติตามสัญญา (Contract) — จำเป็นสำหรับการสร้างบัญชีและหน้าโดเนท
ข้อมูลการรับเงิน (เบอร์, พร้อมเพย์, เลขบัญชีและชื่อเจ้าของบัญชีธนาคาร) การปฏิบัติตามสัญญา (Contract) — จำเป็นสำหรับการรับโดเนท
ข้อมูลการตั้งค่า Dashboard ความยินยอม (Consent) — ผู้ใช้กรอกเอง
Donor message (TTS) ประโยชน์โดยชอบธรรม (Legitimate Interest) — ฟีเจอร์ alert สตรีม
TTS API Key (Google Cloud / Gemini) การปฏิบัติตามสัญญา (Contract) — จำเป็นสำหรับการเรียกใช้บริการ TTS ตามที่สตรีมเมอร์เลือกเปิดใช้งาน
รูปภาพโปรไฟล์ (R2) การปฏิบัติตามสัญญา (Contract) — แสดงผลหน้าโดเนท
Session cookie ความจำเป็นสำคัญ (Strictly Necessary) — ไม่ต้องขอ consent
IP Address + metadata (ip_events) ภาระผูกพันทางกฎหมาย (Legal Obligation) — พ.ร.บ.คอมพิวเตอร์ ม.26 เก็บเพื่อให้สามารถระบุตัวผู้กระทำผิดได้ตามคำขอหน่วยงานรัฐ
เบอร์โทรศัพท์ผู้โอน (mask) จาก TrueMoney Webhook การปฏิบัติตามสัญญา (Contract) + ประโยชน์โดยชอบธรรม (Legitimate Interest) — จำเป็นเพื่อยืนยันการโอนและป้องกัน duplicate transaction (TrueMoney เป็น Controller ของข้อมูลผู้ส่งฝั่งต้นทาง)

7. สิทธิ์ของเจ้าของข้อมูลส่วนบุคคล (Data Subject Rights)

ในฐานะเจ้าของข้อมูลส่วนบุคคลตาม PDPA มาตรา 30-37 คุณมีสิทธิ์ดังต่อไปนี้:

  • สิทธิ์เข้าถึงข้อมูล (Right of Access): ขอดูว่าเราเก็บข้อมูลอะไรของคุณบ้าง
  • สิทธิ์แก้ไขข้อมูล (Right to Rectification): ขอให้แก้ไขข้อมูลที่ไม่ถูกต้อง
  • สิทธิ์ลบข้อมูล (Right to Erasure): ขอให้ลบข้อมูลส่วนบุคคลของคุณ
  • สิทธิ์โต้แย้งการประมวลผล (Right to Object): โต้แย้งการประมวลผลที่อ้าง Legitimate Interest
  • สิทธิ์จำกัดการประมวลผล (Right to Restriction): ขอให้หยุดประมวลผลชั่วคราวระหว่างตรวจสอบ
  • สิทธิ์โอนย้ายข้อมูล (Right to Portability): ขอรับข้อมูลในรูปแบบที่อ่านได้ด้วยเครื่อง

ใช้สิทธิ์โดยติดต่อ contact@tipkub.me เราจะตอบกลับภายใน 30 วัน
