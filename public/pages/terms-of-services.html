1. การสมัครสมาชิกและการใช้บริการ

ในการสมัครสมาชิกเพื่อรับบริการจาก TipKub นั้น ผู้รับบริการต้องมีอายุไม่ต่ำกว่า 13 ปี บริบูรณ์ในวันที่มีการสมัครรับบริการ และในกรณีที่ผู้รับบริการยังไม่บรรลุนิติภาวะตามกฎหมาย ต้องได้รับความยินยอมจากผู้แทนโดยชอบธรรมด้วย

ทางเว็บไซต์ TipKub จะไม่มีการเก็บข้อมูลส่วนบุคคลของผู้ใช้งาน โดยจะเก็บเพียงข้อมูลที่จำเป็นเกี่ยวกับการรับเงินเท่านั้น เช่น หมายเลขโทรศัพท์ เพื่อใช้ในการรับเงินผ่านระบบพร้อมเพย์ เป็นต้น ทั้งนี้ผู้รับบริการต้องแจ้งข้อมูลที่เป็นความจริงต่อผู้ให้บริการ

2. ช่องทางการรับชำระเงินของผู้รับบริการ

ผู้รับบริการจะต้องระบุช่องทางการรับชำระเงินผ่านบัญชี TrueMoney Wallet หรือบัญชีธนาคารภายใต้เงื่อนไขดังต่อไปนี้:

  • ผู้รับบริการต้องระบุหมายเลขโทรศัพท์, หมายเลขบัตรประจำตัวประชาชน, หมายเลขพร้อมเพย์ หรือเลข E-Wallet ID ของพร้อมเพย์ ให้ถูกต้องและเป็นของผู้รับบริการเอง
  • ในกรณีรับชำระผ่านบัญชีธนาคาร ผู้รับบริการต้องระบุชื่อธนาคาร, เลขบัญชีธนาคาร และชื่อเจ้าของบัญชี (ชื่อ-นามสกุลจริง) ให้ถูกต้องครบถ้วนและเป็นบัญชีของผู้รับบริการเอง
  • ผู้รับบริการต้องยืนยันเบอร์โทรศัพท์และที่อยู่อีเมลผ่านรหัส OTP ก่อนทำการเปิดรับชำระเงิน
  • ในกรณีที่ข้อมูลช่องทางการรับชำระเงินไม่ถูกต้อง หรือไม่ครบถ้วน เป็นสาเหตุให้การทำรายการโอนเงินไม่สำเร็จ หรือทำให้โอนเงินผิดไปยังปลายทางที่ไม่ใช่บัญชีของผู้รับบริการ ทาง TipKub จะไม่มีการรับผิดชอบใด ๆ ทั้งสิ้น

3. ค่าธรรมเนียมและการชำระเงิน

แพลตฟอร์ม TipKub ไม่เรียกเก็บค่าธรรมเนียมหรือค่าบริการใด ๆ จากผู้รับบริการสำหรับการรับเงินสนับสนุนผ่านระบบ อย่างไรก็ตาม ค่าธรรมเนียมอาจเกิดขึ้นจากการดำเนินการของบุคคลที่สาม ดังนี้:

  • SlipOK: บริการตรวจสอบสลิปโอนเงินอาจมีค่าธรรมเนียมตามแพ็กเกจที่ผู้รับบริการเลือกสมัครกับ SlipOK โดยตรง ซึ่ง TipKub ไม่มีสิทธิกำหนดหรือควบคุมอัตราค่าธรรมเนียมดังกล่าว
  • TrueMoney Open API (กรณีเปิดใช้งาน Webhook): 100 ธุรกรรมแรกต่อเดือน ไม่มีค่าธรรมเนียม — หากเกินโควตา TrueMoney จะเรียกเก็บ 10฿ ต่อครั้ง จาก TrueMoney Wallet ของผู้รับบริการโดยตรง TipKub ไม่มีส่วนเกี่ยวข้องและไม่ได้รับเงินส่วนนี้
  • ผู้ให้บริการ TTS ภายนอก: ค่าใช้จ่าย TTS จากผู้ให้บริการภายนอกเรียกเก็บกับบัญชี API ของสตรีมเมอร์โดยตรง หากเกินโควต้าฟรี — TipKub ไม่จ่าย ไม่ชดใช้
  • สถาบันการเงิน: ธนาคารหรือผู้ให้บริการบัญชีของผู้รับบริการอาจหักค่าธรรมเนียมตามเงื่อนไขของแต่ละสถาบัน

ผู้รับบริการจะได้รับเงินตามรอบการชำระเงินของแต่ละช่องทาง โดย TipKub ไม่มีหน้าที่รับผิดชอบต่อการล่าช้าหรือข้อขัดข้องที่เกิดจากบุคคลที่สามดังกล่าว

4. กฏระเบียบและข้อบังคับ

ผู้ให้บริการให้บริการ TipKub เพื่อวัตถุประสงค์ในการเป็นแพลตฟอร์มแสดงยอดจำนวนเงินการรับโดเนทบนหน้าจอสตรีมมิ่ง และอนุญาตให้ใช้เพื่อวัตถุประสงค์ในการค้าเชิงพาณิชย์ (เช่น การตั้งระบบหน้าร้านค้าสินค้าที่จัดทำโดยผู้รับบริการเอง) แต่ต้องไม่ใช่สินค้าหรือบริการที่ขัดต่อกฎหมาย ดังนี้:

  • ยาเสพติด, ยาสูบ, บุหรี่, เครื่องดื่มแอลกอฮอล์
  • สินค้าละเมิดทรัพย์สินทางปัญญา, สินค้าปลอม, สินค้าเลียนแบบ
  • สื่อลามกอนาจาร หรือสื่อไปในทางเพศ
  • สินค้าที่เกี่ยวข้องกับความมั่นคง, การปลุกระดม, หรือกระทบต่อการปกครอง
  • สินค้าที่เกี่ยวข้องกับพระบรมวงศานุวงศ์หรือราชวงศ์
  • เงินตรา, แสตมป์ปลอม, บัตรเครดิต/เดบิต, สกุลเงินดิจิทัล
  • อาวุธปืน, เครื่องกระสุน, วัตถุระเบิด, ดอกไม้เพลิง
  • อุปกรณ์การพนัน หรือสินค้าที่เข้าลักษณะของการพนัน
  • สินค้าที่มีฉลากปลอม หรือได้มาโดยไม่ถูกต้องตามกฎหมาย
  • ไอเท็มหรือบริการภายในเกม รวมถึงโค้ดเกม
  • การฟอกเงิน, การแบ่งชำระเพื่อหลีกเลี่ยงการรายงาน (structuring), หรือการกระทำใดๆ ที่ขัดต่อ พ.ร.บ.ป้องกันและปราบปรามการฟอกเงิน

การรับเงินสนับสนุนที่มีสิ่งตอบแทนเป็นผลงานสร้างสรรค์ในรูปแบบดิจิทัล (เช่น การวาดภาพตามคำขอ) ให้ถือเป็นส่วนหนึ่งของระบบการสนับสนุนที่สามารถกระทำได้

การปรับแต่งชื่อ รูปภาพ หรือข้อความในโปรไฟล์ จะต้องไม่บิดเบือน เท็จ ลามก หรือก่อให้เกิดความเสียหายต่อบุคคลอื่น หากตรวจพบผู้ให้บริการมีสิทธิลบข้อมูลดังกล่าวได้ทันทีโดยไม่ต้องแจ้งให้ทราบล่วงหน้า

5. การใช้งาน SlipOK

ข้อจำกัดความรับผิดชอบ: TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการของ SlipOK การใช้งานช่องทางดังกล่าวเป็นเพียงการรองรับการเชื่อมต่อผ่าน API Key ที่ผู้รับบริการนำมาเอง โดยผู้รับบริการต้องสมัครบัญชีกับ SlipOK ด้วยตนเองโดยตรง TipKub ไม่มีสิทธิ์กำหนด ควบคุม หรือรับประกันบริการของ SlipOK ดังกล่าว

สำหรับการใช้งานระบบตรวจสอบสลิปผ่าน SlipOK มีรายละเอียดดังนี้:

  • ผู้รับบริการจำเป็นต้องไปสมัครบัญชี SlipOK ด้วยตนเองผ่านเว็บไซต์ slipok.com
  • ผู้รับบริการเป็นผู้กรอกเลข API ของ SlipOK ลงในระบบของ TipKub
  • เพื่อความปลอดภัย ข้อมูล API ของ SlipOK รวมถึงเบอร์โทรศัพท์และรหัสรับเงินพร้อมเพย์ จะถูกเข้ารหัส (Encryption) ด้วย AES-256-GCM ก่อนที่จะถูกนำไปจัดเก็บลงในฐานข้อมูล (Database) ของทางเว็บไซต์
  • จำนวนครั้งในการตรวจสอบสลิปต่อเดือนขึ้นอยู่กับแพ็กเกจที่ผู้รับบริการเลือกสมัครกับ SlipOK โดยตรง ซึ่งเป็นข้อตกลงระหว่างผู้รับบริการกับ SlipOK เท่านั้น TipKub ไม่มีสิทธิกำหนดหรือควบคุมโควตาดังกล่าว

5.1 การใช้งาน TTS จากผู้ให้บริการภายนอก

ข้อจำกัดความรับผิดชอบ: TipKub ไม่ใช่พันธมิตรหรือตัวแทนอย่างเป็นทางการของผู้ให้บริการ Text-to-Speech (TTS) ภายนอก ได้แก่ Google Cloud TTS, Gemini API และ Microsoft Edge TTS การใช้งานเป็นเพียงการรองรับการเชื่อมต่อผ่าน API Key ที่ผู้รับบริการนำมาเอง TipKub ไม่มีสิทธิ์กำหนด ควบคุม หรือรับประกันบริการของผู้ให้บริการดังกล่าว

  • ผู้รับบริการเป็นผู้สมัครบัญชีและสร้าง API Key กับผู้ให้บริการ TTS ด้วยตนเองโดยตรง
  • เพื่อความปลอดภัย API Key ของผู้ให้บริการ TTS จะถูกเข้ารหัส (Encryption) ด้วย AES-256-GCM ก่อนที่จะถูกนำไปจัดเก็บลงในฐานข้อมูล (Database) ของทางเว็บไซต์ และไม่มีการส่งกลับไปแสดงผลฝั่งผู้ใช้งาน
  • ผู้รับบริการรับรองว่า API Key ที่นำมากรอกเป็นของผู้รับบริการเอง และมีสิทธิ์ใช้งานโดยชอบ
  • ผู้รับบริการต้องปฏิบัติตามข้อกำหนดและเงื่อนไขการให้บริการ (Terms of Service) ของผู้ให้บริการ TTS แต่ละรายด้วยตนเอง ซึ่งเป็นข้อตกลงระหว่างผู้รับบริการกับผู้ให้บริการนั้นโดยตรง
  • การเปิดใช้ฟีเจอร์ทำให้ข้อความโดเนทถูกส่งไปยังผู้ให้บริการ TTS ผู้รับบริการในฐานะผู้ควบคุมข้อมูลส่วนบุคคล (Controller) มีหน้าที่แจ้งผู้บริจาคให้ทราบถึงการส่งข้อมูลดังกล่าว

5.2 ข้อตกลงการประมวลผลข้อมูล (Data Processing Terms)

สำหรับข้อมูลโดเนท (ชื่อผู้บริจาค ข้อความ และรายการบริจาค) ผู้รับบริการเป็นผู้ควบคุมข้อมูลส่วนบุคคล (Controller) และ TipKub ทำหน้าที่เป็นผู้ประมวลผลข้อมูลส่วนบุคคล (Processor) ในนามของผู้รับบริการ โดยประมวลผลตามคำสั่งและการตั้งค่าที่ผู้รับบริการกำหนดไว้ใน Dashboard เท่านั้น

ผู้รับบริการรับทราบและตกลงว่า TipKub ใช้ผู้ประมวลผลช่วง (Sub-Processor) ดังต่อไปนี้ในการให้บริการ:

  • Twitch / Streamlabs — ยืนยันตัวตน (OAuth)
  • SlipOK — ตรวจสอบสลิปโอนเงิน
  • Cloudflare R2 — จัดเก็บและส่งมอบรูปภาพ
  • Turso Cloud — ฐานข้อมูลหลัก
  • TrueMoney (Ascend Money) — ยืนยันการโอนเงินเข้า Wallet (เฉพาะเมื่อเปิดใช้งาน Webhook)
  • Google Cloud TTS, Gemini API, Microsoft Edge TTS — สังเคราะห์เสียงจากข้อความโดเนท (เฉพาะเมื่อเปิดใช้งาน)

รายละเอียดข้อมูลที่ส่งไปยังผู้ประมวลผลช่วงแต่ละราย วัตถุประสงค์ และระยะเวลาการเก็บรักษา ระบุไว้ใน นโยบายความเป็นส่วนตัว ข้อ 3.1

6. การแจ้งเตือนและการตรวจสอบสลิป

TipKub ไม่มีการจำกัดจำนวนครั้งในการแจ้งเตือนโดเนทขึ้นหน้าจอ อย่างไรก็ตาม มีข้อจำกัดทางเทคนิคสำหรับการตรวจสอบสลิปโอนเงิน ดังนี้:

  • ระบบตรวจสอบสลิปโอนเงินใช้บริการ API จาก SlipOK ซึ่งเป็นบุคคลที่สาม ผู้รับบริการต้องสมัครบัญชี SlipOK ด้วยตนเองและนำ API Key มากรอกในระบบของ TipKub
  • จำนวนครั้งในการตรวจสอบสลิปต่อเดือนขึ้นอยู่กับนโยบายและแพ็กเกจที่ผู้รับบริการเลือกสมัครกับ SlipOK โดยตรง ซึ่งเป็นข้อตกลงระหว่างผู้รับบริการกับ SlipOK เท่านั้น TipKub ไม่มีสิทธิกำหนดหรือควบคุมโควตาดังกล่าว และไม่มีหน้าที่รับผิดชอบหากโควต้าหมดหรือแพ็กเกจหมดอายุ
  • หากเซิร์ฟเวอร์ของ SlipOK เกิดขัดข้องหรือล่ม อาจส่งผลให้ระบบตรวจสอบสลิปไม่สามารถทำงานได้ตามปกติ
  • ทางเว็บไซต์จะมีระบบแจ้งเตือนให้ผู้โดเนททราบก่อนกดโอนเงินว่าระบบตรวจสลิปในขณะนั้นทำงานปกติหรือไม่ หากระบบผิดปกติ ระบบจะแจ้งเตือนผู้โดเนทโดยอัตโนมัติ

7. การรักษาความปลอดภัย

ทางเว็บไซต์ TipKub ไม่มีการเก็บรหัสผ่านของผู้ใช้งาน แต่จะเก็บข้อมูลสำคัญที่จำเป็นต่อการให้บริการ ดังนี้:

  • ข้อมูล API ของ SlipOK: Branch URL และ API Key ที่ผู้รับบริการกรอก จะถูกเข้ารหัสด้วย AES-256-GCM ก่อนนำขึ้นไปเก็บในฐานข้อมูล เพื่อป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต
  • เบอร์โทรศัพท์และรหัสรับเงินพร้อมเพย์: ข้อมูลการรับเงินของผู้รับบริการจะถูกเข้ารหัสก่อนบันทึกลงฐานข้อมูล กุญแจถอดรหัสจะถือโดยผู้ให้บริการเท่านั้น
  • เลขบัญชีและชื่อเจ้าของบัญชีธนาคาร: เลขบัญชีธนาคารและชื่อเจ้าของบัญชี (ชื่อ-นามสกุลจริง) จะถูกเข้ารหัสด้วย AES-256-GCM ก่อนบันทึกลงฐานข้อมูลเช่นเดียวกัน (ชื่อธนาคารเป็นข้อมูลทั่วไป ไม่มีการเข้ารหัส)

เกี่ยวกับข้อมูลสลิปโอนเงิน:

  • รูปภาพสลิปที่ผู้โดเนทอัพโหลดจะถูกส่งไปยัง SlipOK API เพื่อตรวจสอบเท่านั้น ไม่มีการจัดเก็บไฟล์สลิปไว้ที่ Server ของ TipKub เด็ดขาด
  • ระบบจะบันทึกเฉพาะข้อมูลผลลัพธ์จากการตรวจสอบ (เช่น ยอดเงิน, เลขอ้างอิง, ชื่อผู้โอน) ลงในฐานข้อมูล เพื่อใช้ในการยืนยันการชำระเงิน

8. การเก็บรักษาข้อมูลและระยะเวลา

เพื่อความปลอดภัยของข้อมูลและความเป็นส่วนตัว TipKub มีนโยบายการจัดเก็บข้อมูลดังนี้:

  • รายการบริจาคคงค้าง (Pending): รายการที่รอการชำระเงินจะถูกทำเครื่องหมายเป็นหมดอายุโดยอัตโนมัติหากไม่มีการชำระเงินภายใน 30 นาที
  • ข้อมูลหมดอายุ (Expired): รายการที่หมดอายุแล้วจะถูกลบออกจากระบบโดยอัตโนมัติภายใน 7 วัน
  • รอบการรีเซทข้อมูล: ระบบจะทำการล้างรายการบริจาคทั้งหมดที่มีอายุเกิน 6 เดือน (180 วัน) โดยอัตโนมัติในทุกๆ 6 เดือน ผู้รับบริการสามารถดาวน์โหลดประวัติการบริจาคของตนเองได้จากหน้า Dashboard ก่อนข้อมูลจะถูกลบ
  • ผู้รับบริการสามารถดาวน์โหลดประวัติรายการบริจาคย้อนหลังได้ด้วยตนเองผ่านหน้า Dashboard ได้ตลอดเวลา

9. การปรับปรุงและการเปลี่ยนแปลง

ผู้ให้บริการขอสงวนสิทธิในการเปลี่ยนแปลงข้อกำหนดและเงื่อนไขการให้บริการ โดยจะแจ้งให้ทราบล่วงหน้าอย่างน้อย 7 วันผ่านการประกาศบนเว็บไซต์ tipkub.me และ/หรืออีเมล (กรณีมีการลงทะเบียนอีเมลไว้) การใช้บริการต่อเนื่องหลังจากวันมีผลบังคับใช้ถือว่าผู้รับบริการยอมรับข้อกำหนดที่เปลี่ยนแปลงแล้ว

10. ขอบเขตความรับผิดและการชดเชย

10.1 การจำกัดความรับผิด (Limitation of Liability)

  • ความเสียหายทางอ้อม (indirect), พิเศษ (special), หรือเป็นผลสืบเนื่อง (consequential) ที่เกิดจากการใช้หรือไม่สามารถใช้บริการได้
  • ความสูญเสียรายได้หรือกำไรอันเกิดจากระบบขัดข้อง
  • การกระทำของบุคคลที่สาม (Twitch, Streamlabs, SlipOK, ผู้ให้บริการ TTS ภายนอก (Google Cloud TTS, Gemini API, Microsoft Edge TTS), ธนาคาร, ผู้บริจาค)
  • ความเสียหายที่เกิดจากข้อมูลการรับเงินที่ไม่ถูกต้องซึ่งผู้รับบริการกรอกเอง
  • บริการ TTS จากผู้ให้บริการภายนอก โดย TipKub ไม่รับประกันความพร้อมใช้งาน คุณภาพ หรือความถูกต้องของเสียงที่สังเคราะห์ได้

ความรับผิดสูงสุดของ TipKub ต่อกรณีใดๆ จำกัดที่ศูนย์บาท (0 บาท) เนื่องจากแพลตฟอร์มไม่เรียกเก็บค่าบริการ
