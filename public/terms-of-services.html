1. การสมัครสมาชิกและการใช้บริการ

ในการสมัครสมาชิกเพื่อรับบริการจาก TipKub นั้น ผู้รับบริการต้องมีอายุไม่ต่ำกว่า 13 ปี บริบูรณ์ในวันที่มีการสมัครรับบริการ และในกรณีที่ผู้รับบริการยังไม่บรรลุนิติภาวะตามกฎหมาย ต้องได้รับความยินยอมจากผู้แทนโดยชอบธรรมด้วย

ทางเว็บไซต์ TipKub จะไม่มีการเก็บข้อมูลส่วนบุคคลของผู้ใช้งาน โดยจะเก็บเพียงข้อมูลที่จำเป็นเกี่ยวกับการรับเงินเท่านั้น เช่น หมายเลขโทรศัพท์ เพื่อใช้ในการรับเงินผ่านระบบพร้อมเพย์ เป็นต้น ทั้งนี้ผู้รับบริการต้องแจ้งข้อมูลที่เป็นความจริงต่อผู้ให้บริการ

2. ช่องทางการรับชำระเงินของผู้รับบริการ

ผู้รับบริการจะต้องระบุช่องทางการรับชำระเงินผ่านบัญชี TrueMoneyWallet หรือบัญชีธนาคารภายใต้เงื่อนไขดังต่อไปนี้:

  • ผู้รับบริการต้องระบุหมายเลขโทรศัพท์, หมายเลขพร้อมเพย์ หรือเลข E-Wallet ID ของพร้อมเพย์ ให้ถูกต้องและเป็นของผู้รับบริการเอง
  • ผู้รับบริการต้องยืนยันเบอร์โทรศัพท์และที่อยู่อีเมลผ่านรหัส OTP ก่อนทำการเปิดรับชำระเงิน
  • ในกรณีที่ข้อมูลช่องทางการรับชำระเงินไม่ถูกต้อง หรือไม่ครบถ้วน เป็นสาเหตุให้การทำรายการโอนเงินไม่สำเร็จ หรือทำให้โอนเงินผิดไปยังปลายทางที่ไม่ใช่บัญชีของผู้รับบริการ ทาง TipKub จะไม่มีการรับผิดชอบใด ๆ ทั้งสิ้น

3. ค่าธรรมเนียมและการชำระเงิน

ผู้ให้บริหารจะไม่หักค่าธรรมเนียมหรือค่าบริการใด ๆ เมื่อมีการโอนหรือรับชำระเงินผ่านช่องทางการรับชำระเงินที่ได้ลงทะเบียนไว้ เว้นแต่ธนาคารหรือผู้ให้บริการบัญชีของผู้รับบริการจะมีการหักค่าธรรมเนียมเอาไว้ ตามเงื่อนไขการให้บริการของผู้ให้บริการบัญชีนั้น ๆ ทั้งนี้ผู้รับบริการจะได้รับชำระเงินทันทีเว้นแต่เป็นไปตามเงื่อนไขของธนาคารหรือผู้ให้บริการบัญชี

4. กฏระเบียบและข้อบังคับ

ผู้ให้บริการให้บริการ TipKub เพื่อวัตถุประสงค์ในการเป็นแพลตฟอร์มแสดงยอดจำนวนเงินการรับโดเนทบนหน้าจอสตรีมมิ่ง และอนุญาตให้ใช้เพื่อวัตถุประสงค์ในการค้าเชิงพาณิชย์ (เช่น การตั้งระบบหน้าร้านค้าสินค้าที่จัดทำโดยผู้รับบริการเอง) แต่ต้องไม่ใช่สินค้าหรือบริการที่ขัดต่อกฎหมาย ดังนี้:

  • ยาเสพติด, ยาสูบ, บุหรี่, เครื่องดื่มแอลกอฮอล์
  • สินค้าละเมิดทรัพย์สินทางปัญญา, สินค้าปลอม, สินค้าเลียนแบบ
  • สื่อลามกอนาจาร หรือสื่อไปในทางเพศ
  • สินค้าที่เกี่ยวข้องกับความมั่นคง, การปลุกระดม, หรือกระทบต่อการปกครอง
  • สินค้าที่เกี่ยวข้องกับพระบรมวงศานุวงศ์หรือราชวงศ์
  • เงินตรา, แสตมป์ปลอม, บัตรเครดิต/เดบิต, สกุลเงินดิจิทัล
  • อาวุธปืน, เครื่องกระสุน, วัตถุระเบิด, ดอกไม้เพลิง
  • อุปกรณ์การพนัน หรือสินค้าที่เข้าลักษณะของการพนัน
  • สินค้าที่มีฉลากปลอม หรือได้มาโดยไม่ถูกต้องตามกฎหมาย
  • ไอเท็มหรือบริการภายในเกม รวมถึงโค้ดเกม

การรับเงินสนับสนุนที่มีสิ่งตอบแทนเป็นผลงานสร้างสรรค์ในรูปแบบดิจิทัล (เช่น การวาดภาพตามคำขอ) ให้ถือเป็นส่วนหนึ่งของระบบการสนับสนุนที่สามารถกระทำได้

การปรับแต่งชื่อ รูปภาพ หรือข้อความในโปรไฟล์ จะต้องไม่บิดเบือน เท็จ ลามก หรือก่อให้เกิดความเสียหายต่อบุคคลอื่น หากตรวจพบผู้ให้บริการมีสิทธิลบข้อมูลดังกล่าวได้ทันทีโดยไม่ต้องแจ้งให้ทราบล่วงหน้า

5. การใช้งาน FeelFreePay (FFP)

สำหรับการใช้งานช่องทาง FeelFreePay มีรายละเอียดดังนี้:

  • ผู้รับบริการจำเป็นต้องไปสมัครบัญชี FeelFreePay ด้วยตนเองผ่านเว็บไซต์ Official ของ FeelFreePay
  • ผู้รับบริการเป็นผู้กรอกเลข API หรือข้อมูลบัญชี FFP ของตนเองลงในระบบของ TipKub
  • เพื่อความปลอดภัย ข้อมูล API และข้อมูลลับต่างๆ จะถูกเข้ารหัส (Encryption) ก่อนที่จะถูกนำไปจัดเก็บลงในฐานข้อมูล (Database) ของทางเว็บไซต์
  • การใช้งานช่องทาง FFP ไม่มีการจำกัดจำนวนครั้งในการแจ้งเตือน และไม่มีความแตกต่างด้านฟีเจอร์การใช้งานเว็บเมื่อเทียบกับช่องทางอื่น

6. การแจ้งเตือนและการตรวจสอบสลิป

TipKub ไม่มีการจำกัดจำนวนครั้งในการแจ้งเตือนโดเนทขึ้นหน้าจอ อย่างไรก็ตาม มีข้อจำกัดทางเทคนิคสำหรับการรับเงินโดยวิธีอ่านสลิปโอนเงิน (ที่ไม่ใช่ผ่านระบบ FFP) ดังนี้:

  • ระบบการอ่านสลิปโอนเงินเป็นการใช้งาน API รูปแบบฟรี หากเซิร์ฟเวอร์ต้นทางของ API เกิดขัดข้องหรือล่ม อาจส่งผลให้ระบบแจ้งเตือนไม่สามารถทำงานได้ตามปกติ
  • ทางเว็บไซต์จะมีระบบแจ้งเตือนให้ผู้โดเนททราบก่อนกดโอนเงินว่าระบบตรวจสลิปในขณะนั้นทำงานปกติหรือไม่ หากระบบผิดปกติ ระบบจะแจ้งเตือนผู้โดเนทโดยอัตโนมัติ

7. การรักษาความปลอดภัย

ทางเว็บไซต์ TipKub ไม่มีการเก็บรหัสผ่านของผู้ใช้งาน แต่จะเก็บข้อมูลสำคัญ เช่น ข้อมูล API ของ FeelFreePay โดยข้อมูลลับเหล่านี้จะถูกเข้ารหัสก่อนนำขึ้นไปเก็บในฐานข้อมูล เพื่อป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต

รูปภาพและข้อมูลที่จำเป็นสำหรับการรับเงิน จะถูกจัดเก็บไว้ที่ Cloudflare R2 และมีการเข้ารหัสไว้ โดยกุญแจถอดรหัสจะถือโดยผู้ให้บริการเท่านั้น

8. การปรับปรุงและการเปลี่ยนแปลง

ผู้ให้บริการขอสงวนสิทธิในการเปลี่ยนแปลงข้อกำหนดและเงื่อนไขการให้บริการได้ทุกเมื่อ โดยไม่ต้องขอความยินยอมจากผู้รับบริการ
