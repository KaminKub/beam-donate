นโยบายความเป็นส่วนตัว

1. ข้อมูลที่เราเก็บรวบรวม

เพื่อการใช้งานแพลตฟอร์ม TipKub เรามีการเก็บรวบรวมข้อมูลที่จำเป็นดังนี้:

  • ข้อมูลจาก Twitch: เราใช้ระบบ OAuth ของ Twitch เพื่อยืนยันตัวตน โดยเก็บข้อมูลพื้นฐาน เช่น Twitch ID, ชื่อผู้ใช้งาน (Username) และรูปโปรไฟล์ เพื่อใช้ในการสร้างและจัดการหน้าโดเนทของคุณ
  • ข้อมูลที่ไม่มีการจัดเก็บ: เพื่อความเป็นส่วนตัวสูงสุด ระบบของเราไม่มีการเก็บข้อมูลอีเมล (Email) หรือรหัสผ่าน (Password) ของผู้ใช้งานในฐานข้อมูลโดยเด็ดขาด
  • ข้อมูลการตั้งค่า: ข้อมูลการปรับแต่งหน้าโดเนทที่คุณกำหนดเองใน Dashboard จะถูกบันทึกไว้ในฐานข้อมูลของเรา
  • ข้อมูลการรับเงิน: ข้อมูลที่จำเป็นสำหรับการรับเงิน เช่น เบอร์โทรศัพท์, หมายเลขบัตรประจำตัวประชาชน, หรือรหัสรับเงินพร้อมเพย์ จะถูกเก็บไว้ในฐานข้อมูล โดยจะถูกเข้ารหัสด้วย AES-256-GCM ก่อนจัดเก็บเสมอ
  • ข้อมูล API ของบุคคลที่สาม: ข้อมูล API ของ SlipOK ที่ผู้ใช้งานกรอกเองจะถูกเข้ารหัสก่อนจัดเก็บเช่นกัน (TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการของ SlipOK)

2. การใช้คุกกี้ (Cookies)

เราใช้คุกกี้ประเภท Strictly Necessary Cookies ซึ่งมีความจำเป็นอย่างยิ่งต่อการทำงานของเว็บไซต์:

  • ใช้สำหรับรักษาเซสชัน (Session) การล็อกอินของคุณ เพื่อให้คุณสามารถจัดการหน้า Dashboard ได้อย่างต่อเนื่องโดยไม่ต้องล็อกอินใหม่ทุกครั้งที่เปลี่ยนหน้า

3. การรักษาความปลอดภัยและการแบ่งปันข้อมูล

เราให้ความสำคัญกับความเป็นส่วนตัวของคุณอย่างสูงสุด:

  • เราไม่มีการขายข้อมูลส่วนบุคคลของคุณให้กับบุคคลที่สาม
  • ข้อมูลการเชื่อมต่อ API ของบริการชำระเงิน (SlipOK ซึ่ง TipKub ไม่ใช่พันธมิตรอย่างเป็นทางการ) รวมถึงเบอร์โทรศัพท์และรหัสรับเงินพร้อมเพย์จะถูกเข้ารหัสด้วย AES-256-GCM และเก็บรักษาเป็นความลับ ใช้เพื่อการประมวลผลยอดบริจาคเท่านั้น
  • กุญแจถอดรหัส (Encryption Key) จะถูกเก็บรักษาโดยผู้ให้บริการเท่านั้น ไม่มีการเปิดเผยต่อบุคคลที่สาม

4. นโยบายเกี่ยวกับข้อมูลสลิปโอนเงิน

เกี่ยวกับการตรวจสอบสลิปโอนเงินผ่านระบบของ TipKub:

  • ไม่มีการจัดเก็บไฟล์สลิป: รูปภาพสลิปที่ผู้โดเนทอัพโหลดจะถูกส่งไปยัง SlipOK API เพื่อตรวจสอบเท่านั้น ไม่มีการจัดเก็บไฟล์สลิปไว้ที่ Server ของ TipKub เด็ดขาด เมื่อการตรวจสอบเสร็จสิ้น ไฟล์สลิปจะถูกลบออกจากหน่วยความจำของเซิร์ฟเวอร์ทันที
  • ข้อมูลที่บันทึก: ระบบจะบันทึกเฉพาะข้อมูลผลลัพธ์จากการตรวจสอบ เช่น ยอดเงินโอน, เลขอ้างอิงธุรกรรม, และชื่อผู้โอน ลงในฐานข้อมูล เพื่อใช้ในการยืนยันการชำระเงินและแสดงใน Dashboard
  • SlipOK เป็นบุคคลที่สาม: การตรวจสอบสลิปดำเนินการโดย SlipOK ซึ่งเป็นบริการบุคคลที่สาม ผู้ใช้งานต้องสมัครบัญชีกับ SlipOK โดยตรง และยอมรับนโยบายความเป็นส่วนตัวของ SlipOK แยกต่างหาก
